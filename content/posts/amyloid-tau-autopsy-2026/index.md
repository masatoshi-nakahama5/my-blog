アルツハイマー型認知症の新しい薬は、脳にたまった「ゴミ」を取りのぞく薬です。

では、ゴミを取りのぞくと、脳の中では本当に何かが変わるのでしょうか。

2026年、アメリカのペンシルベニア大学のチームが、**薬の治療を受けたあとに亡くなった、ひとりの男性の脳**をくわしく調べた結果を発表しました。

> ✅ **1人だけを調べた報告**です。薬でアミロイドがほとんど消えていた場所では、もうひとつのゴミ「タウ」も、治療を受けていない人の脳にくらべて少なくなっていました
>
> ✅ 一方、同じ脳の中でもアミロイドが残っていた場所では、タウは**治療を受けていない人と同じくらい**ありました
>
> ✅ 使われたのは、いまは販売が終わっている古い薬です。「早く治療すれば防げる」とまでは、この1例からは言えません

## アミロイドとタウ、ふたつのゴミ

アルツハイマー型認知症の脳には、2種類のゴミがたまることが知られています。

- **アミロイドβ**（ベータ）……神経細胞の**外**にたまる、ねばねばしたたんぱく質のかたまり。先にたまりはじめます
- **タウ**……神経細胞の**中**にたまり、もつれた糸のようになるたんぱく質。神経細胞が弱っていくことと、深く関係していると考えられています

いま日本で使われている新しい薬（レカネマブ・ドナネマブ）は、点滴で**アミロイドβを取りのぞく**薬です。

ただ、「アミロイドを取りのぞけば、そのあとのタウや、脳がやせていくことも抑えられるのか」は、**人の脳では、まだよく分かっていませんでした**。

{{< fukidashi who="reader" >}}
薬の試験で「進行がゆるやかになった」と聞きましたが、それとは違うんですか？
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
試験で分かるのは、もの忘れなどの**症状の変わり方**です。脳の中でタウがどうなったかを、**目で見て確かめる**には、亡くなったあとに脳を調べるしかありません。そういう機会は、とても少ないんです。
{{< /fukidashi >}}

## 亡くなったあとの脳を、くわしく調べた

調べられたのは、**50代で、軽いもの忘れの段階**と診断された男性です（軽度認知障害＝日常生活はおおむね自分でできるが、もの忘れが目立つ段階のこと）。

この方は、アルツハイマー型認知症に**なりやすさに関わる遺伝子の変化**（TREM2という遺伝子）を持っていました。

- 薬の試験に参加し、**アデュカヌマブ**という抗アミロイド薬を受けた
- **4年半のあいだに、30回**の点滴を受けた
- **最後の点滴から4年後**に亡くなり、亡くなったあとに脳がくわしく調べられた

研究チームは、この方の脳を顕微鏡でくわしく調べ、**治療を受けていない14人の脳**（年齢、または同じ遺伝子の変化の有無をそろえた人たち）とくらべました。

このように、**ひとりの方を、時間をかけてくわしく調べた報告**を「症例報告」といいます。たくさんの人を集めてくらべる研究とは違い、ひとりの中で起きたことを細かく見られる反面、「ほかの人でも同じか」は分かりません。

さらに、**生きているあいだに撮っていた画像検査**（PET＝脳にたまったゴミを映す検査、MRI＝脳の形を映す検査）も、あわせて調べています。

{{< fukidashi who="reader" >}}
アデュカヌマブって、聞いたことがない薬です。
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
アメリカで最初に、早い段階の承認を受けた抗アミロイド薬です。ただ、**いまは販売が終わっていて、日本では使われていません**。いま日本で使われているレカネマブやドナネマブとは、別の薬だということは覚えておいてください。
{{< /fukidashi >}}

## 「山」は片づき、「谷」には残っていた

脳の表面には、たくさんの「しわ」があります。盛り上がった**山の部分**と、その間の**谷の奥**があります。

調べてみると、この方の脳は、場所によってアミロイドの残り方が**まだら**でした。

| 場所 | アミロイド | タウ |
|---|---|---|
| しわの山 | ほぼ消えた | **少なめ** |
| しわの谷の奥 | 多く残った | **同じくらい** |

※タウの量は、治療を受けていない14人の脳とくらべたものです。

つまり、**同じひとりの脳の中で、「アミロイドがよく取れた場所」と「取れなかった場所」が隣り合っていた**のです。

さらに、生前のMRIを見直すと、**アミロイドが少なくなった場所では、脳がやせていくスピードがゆるやかだった**という関係も見られました。

アミロイドが残った場所でも、脳の表面に近い層では量が少なく、**深い層にたくさん残っていました**。薬が届きやすい場所と、届きにくい場所があるのかもしれません。

{{< fukidashi who="reader" >}}
それなら、アミロイドをしっかり取れば、タウも防げるということですか？
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
研究チームも「**しっかり取りきることが必要なのかもしれない**」と考えています。ただ、これは**1人の脳**で見られたことです。アミロイドが取れたからタウが少なかったのか、もともとタウがたまりにくい場所だったからアミロイドも取れやすかったのか、そこまでは決められません。
{{< /fukidashi >}}

## この研究から言えること、言えないこと

**言えること**

- 薬でアミロイドがほとんど消えた場所では、タウが少なく、脳のやせ方もゆるやかだった
- 取れ方には「むら」があり、しわの山では取れやすく、谷の奥では残りやすかった

**言えないこと**

- **1人だけの報告**です。ほかの人にも同じことが起きるかは分かりません
- アミロイドを取ったことが「原因」で、タウが少なくなったとまでは言えません
- 使われたのは**アデュカヌマブ**で、いま日本で使われている薬で同じことが起きるかは分かりません

報道では、研究チームが「早い段階で、しっかり取りのぞくことが大事なのかもしれない」と話しています。また、薬の試験はふつう1年半ほどで結果を判断するため、**もっと長い時間がたってから出てくる違いを見のがしているかもしれない**、とも指摘しています。

ただし、これは研究チームの「**そうかもしれない**」という考えで、まだ確かめられたわけではありません。この1例だけで「早く治療すれば認知症を防げる」と分かったわけではありません。

## いま、私たちにできること

- ☑ **ニュースの「ひとりの例」は、ひとりの例として受けとめる**……とても貴重な報告ですが、「誰にでも当てはまる」とは限りません
- ☑ **新しい薬が気になったら、かかりつけ医や、もの忘れ外来で相談する**……使えるかどうかは、症状の段階や検査で決まります
- ☑ **薬の話と、毎日の暮らしの話は、別々に考える**……運動・睡眠・人とのつながりなど、暮らしの工夫は、薬を使う・使わないにかかわらず続けられます
- ☑ **脳の研究に協力するという選択肢があることを知っておく**……今回の発見は、亡くなったあとに脳を調べることへの協力があって生まれました

## おわりに

アミロイドを取りのぞく薬が、脳の中で本当に何をしているのか。それを確かめる手がかりは、まだとても少ないのが実情です。

今回は、**たった1人の脳**から分かったことです。それでも、「アミロイドがよく取れた場所では、タウも少なかった」という様子を、人の脳で直接見ることができたのは、大切な一歩だと思います。

そして、この一歩は、亡くなったあとに脳を調べることに協力してくださった方々のおかげです。その思いが、これからの研究につながっていくことを願っています。
