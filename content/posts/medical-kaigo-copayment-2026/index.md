前回の記事では、健康保険・介護保険・厚生年金の **「払う側」** の仕組みを見ました。今回はその続きとして、病院や介護サービスを **「使う側」** になったとき、実際に窓口でいくら払うのかを整理します。

結論から言うと、日本の制度には **「二重の守り」** があります。窓口での支払いが1〜3割で済むことと、それでも大きくなったときの **「上限」の仕組み** です。

> ✅ 医療費の窓口負担は年齢と所得で **1〜3割**。介護サービスも同じく **1〜3割**
>
> ✅ 医療費が大きくなっても、**高額療養費制度** で月の支払いに上限がある（例：年収500万円なら月9万円弱）
>
> ✅ 介護にも **高額介護サービス費** という上限があり、一般的な所得なら **月44,400円** でストップ

## 病院の窓口で払うお金：年齢で1〜3割

![診察を受ける患者と医師のイラスト](images/medical-payment.png)

病院や薬局で払うお金は、かかった医療費の全額ではなく、その **一部（自己負担分）** だけです。割合は年齢によって決まっています。

| 年齢 | 窓口での負担割合 |
|---|---|
| 小学生〜69歳 | 3割 |
| 70〜74歳 | 2割（現役並み所得の方は3割） |
| 75歳以上 | 1割（一定以上の所得の方は2割、現役並み所得の方は3割） |

※未就学のお子さんは2割ですが、多くの市町村に子ども医療費の助成があります。

たとえば風邪の診察と薬で医療費が5,000円かかった場合、69歳までの方の窓口負担は1,500円。残りの3,500円は、みんなで払っている保険料と公費でまかなわれています。

75歳以上の方でも、**年金などの収入が一定以上あると2割負担** になる仕組みが2022年から始まっています。毎年送られてくる **保険証（資格確認書）やマイナ保険証の負担割合** で、ご自身の割合を確認できますよ。

## 医療費が大きくなったら：高額療養費制度

![安心してほっとしている人のイラスト](images/kougaku-relief.png)

「3割負担」と聞くと、大きな手術や入院のときが心配になります。医療費が100万円なら、3割でも30万円……。

ここで登場するのが **高額療養費制度**（こうがくりょうようひせいど）です。**1か月（同じ月の1日〜末日）の自己負担には、所得に応じた上限** が決められていて、それを超えた分は戻ってきます。

たとえば **69歳以下・年収約370〜770万円** の方の上限は、

> 80,100円 ＋（医療費 − 267,000円）× 1%

という式で計算されます。医療費100万円の入院なら、窓口3割の30万円ではなく、**最終的な負担は約8万7千円** で済む計算です。

知っておきたいポイントが3つあります。

- **マイナ保険証を使えば、手続きなしで窓口支払いが最初から上限までになる**（従来の「限度額適用認定証」の事前申請が不要に）
- 70歳以上の方は上限がさらに低めに設定されています（例：一般的な所得なら外来は月18,000円まで）
- **2026年8月から上限額が引き上げられます**（例：上の式の80,100円が85,800円に）。住民税非課税の方の上限は据え置かれ、長く療養する方への配慮として年間の上限も新設されます

{{< fukidashi who="reader" >}}
「30万円」と「約8万7千円」では、心構えがぜんぜん違います……！
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
そうなんです。**「医療費で家計が破綻しないための最後の砦」** と言われる制度です。入院が決まったら、まず「高額療養費」を思い出してください。差額ベッド代や食事代など対象外の費用もあるので、詳しくは病院の会計窓口や加入先の健康保険に聞くのが確実です。
{{< /fukidashi >}}

## 介護保険を使うときの流れと自己負担

![ケアマネジャーへの相談のイラスト](images/caremanager-soudan.png)

介護保険のサービスは、病院と違って「行けばすぐ使える」ものではなく、次の流れをたどります。

1. **市町村の窓口に「要介護認定」を申請する**
2. 調査・審査を経て、**要支援1・2 〜 要介護1〜5** の区分が決まる
3. **ケアマネジャー**（＝介護の計画づくりの専門家）と相談して、ケアプランを作る
4. サービスを利用し、**かかった費用の1〜3割** を払う

負担割合は所得によって決まり、**多くの方は1割** です。毎年届く「負担割合証」で確認できます。

もうひとつ大事なのが、**要介護度ごとに「保険が使える月の上限枠（区分支給限度額）」が決まっている** ことです。

| 要介護度 | 月の上限枠（目安） | 1割負担の場合の支払い（目安） |
|---|---|---|
| 要介護1 | 約16万7千円分 | 約1万7千円 |
| 要介護3 | 約27万円分 | 約2万7千円 |
| 要介護5 | 約36万2千円分 | 約3万6千円 |

※1単位＝約10円で換算した目安です（地域により少し異なります）。枠を超えて使った分は全額自己負担になります。このほか、施設やデイサービスでの食費・居住費などは別途かかります。

{{< fukidashi who="reader" >}}
デイサービスに週2回通うと、いくらぐらいなんでしょう？
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
事業所の規模や利用時間で変わりますが、**1割負担の方が週2回・1日7時間ほど通う場合、1か月で1万円前後＋食費** というケースが多い印象です。リハビリの現場でも「デイって高いんでしょう？」とよく聞かれるのですが、実際の金額を聞いて「それなら通えそう」とほっとされる方が多いんですよ。
{{< /fukidashi >}}

## 介護費用にも「上限」があります

医療の高額療養費と同じように、介護にも **高額介護サービス費** という上限の仕組みがあります。

1か月の自己負担（1〜3割の合計）が上限を超えると、超えた分が後から戻ってきます。**一般的な所得の世帯なら、上限は月44,400円** です。

さらに、**医療と介護の両方で負担が重なった世帯** には、1年間の合計に上限を設ける「高額医療・高額介護合算制度」もあります。「医療も介護も両方かかって大変」というご家庭ほど、使える仕組みが用意されているのです。

## 困ったときの相談窓口

費用の心配は、一人で抱え込まずに相談するのがいちばんの近道です。

- ☑ **介護のこと全般** → お住まいの **地域包括支援センター**（65歳以上の方の総合相談窓口・無料）
- ☑ **要介護認定・介護保険料・負担割合** → 市町村の介護保険窓口
- ☑ **医療費・高額療養費** → 加入先の健康保険（協会けんぽ・健保組合・市町村の国保窓口）
- ☑ **入院費用の見通し** → 病院の **医療ソーシャルワーカー**（相談室）。入院が決まった段階で相談できます

## おわりに

「医療や介護はお金がかかる」というイメージは、たしかに間違いではありません。けれど、**窓口負担は1〜3割で済み、大きくなっても上限がある**――この二重の守りを知っているかどうかで、いざというときの不安は大きく変わります。

私自身、現場で費用の質問を受けるたびに感じるのは、**制度は「知っている人」を守ってくれる** ということです。使える仕組みを知らずに、サービスの利用をためらってしまうのが、いちばんもったいないことだと思います。

金額や上限は所得や市町村によって変わり、制度も毎年少しずつ見直されます（この記事の数字は **2026年度時点** のものです）。実際の金額は、必ずお住まいの市町村・ご加入の健康保険・ケアマネジャーにご確認ください。
