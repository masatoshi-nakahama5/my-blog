「パーキンソン病と言われてから、外に出るのがおっくうになった」。

そう感じている方も、いらっしゃるかもしれません。パーキンソン病というと、手のふるえや動きにくさが思い浮かびますが、**物忘れや、考える力の衰え**が心配になる方も少なくありません。

2026年10月、**パーキンソン病の人でも、よく体を動かしている人ほど、考える力の衰えがゆっくりだった**という研究が発表されました。

> ✅ アメリカで、軽い〜中くらいのパーキンソン病の人294人を追った研究で、**体をよく動かしている人ほど、考える力の衰えも、体の動きにくさの進み方も、ゆっくり**でした
>
> ✅ 大事だったのは、運動の**激しさより、動いている時間の長さ**。そして、若いころより**いま動いているか**でした
>
> ✅ ただし「関係が見られた」という研究で、**運動のおかげで進行が遅くなったとまでは言えません**

## パーキンソン病と「考える力」

パーキンソン病は、脳の中で**ドーパミン**（体の動きをなめらかにする物質）を作る細胞が、少しずつ減っていく病気です。

手足のふるえ、動きがゆっくりになる、歩幅が小さくなる、といった**体の症状**がよく知られています。そのほかに、病気が進むにつれて、**物忘れや、段取りを考える力が衰えてくる人もいます**。

体の病気だと思っていました。頭のほうにも関係があるんですね。
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
そうなんです。だからこそ、**体と頭の両方を、どう守っていくか**が大事になります。今回の研究は、その両方を一緒に追いかけたものです。
{{< /fukidashi >}}

## よく動く人ほど、衰えがゆっくり

研究は、アメリカ・シンシナティ大学のチームによるもので、学術誌『Neurology』に2026年10月に発表されました。

- 対象：**軽い〜中くらいのパーキンソン病の人294人**（平均66歳・女性は3人に1人）
- 2019年から2025年にかけて参加した人を、**頭の働きは最長5年、体の動きは最長7年**追いかけました
- 運動は、**聞き取り**で「どんな活動を、週に何時間しているか」を調べました
- 頭の働きは、**30点満点のテスト**（MoCA＝言葉や図形、計算などで、考える力を測る検査）で、毎年測りました

運動している時間の合計で、**少ない組・中くらいの組・多い組**の3つに分けて比べています。発表元の説明では、**少ない組は週4時間まで、中くらいの組は週4〜8時間、多い組は週8時間を超える**人たちです。

結果は、次のとおりでした。

| 運動している時間 | 頭のテストの点数の変化（1年あたり） |
|---|---|
| 少ない組（週4時間まで） | 約0.5点ずつ下がった |
| 中くらいの組（週4〜8時間） | 約0.1点ずつ下がった |
| 多い組（週8時間を超える） | ほとんど変わらなかった |

※研究チームが計算で出した、それぞれの組の平均的な変化です。

年齢や性別、病気になってからの年数などをそろえて比べても、**多い組は少ない組にくらべて、頭の働きの衰えがゆっくり**でした。

手足の動かしにくさ（医師が診察して点数をつける検査）も、**多い組のほうが、悪くなり方がゆっくり**でした。ただし、こちらの差は、**偶然とは言いにくい、ぎりぎりのところ**でした。

{{< fukidashi who="reader" >}}
1年で0.5点……。それって、大きな差なんでしょうか？
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
1年だけ見ると、**小さな差**です。研究チームも「差は小さい」と認めています。ただ、パーキンソン病は長く付き合っていく病気です。**小さな差でも、年月が重なると意味が出てくるかもしれない**、というのが研究チームの見方です。
{{< /fukidashi >}}

## 激しさより「時間」、昔より「いま」

この研究では、もう2つ、おもしろいことが分かりました。

**① 大事なのは、激しさより「時間」**

ジョギングのような**激しい運動**をしている人も、良い結果でした。ところが、**動いている時間の合計をそろえて比べると、激しさによる差は見られなくなりました**。

つまり、激しい運動でなくても、**動いている時間が長いこと**のほうが、関係が強かったのです。

では、激しくない運動とは、どんなものでしょう。発表元の説明では、ジョギングほどきつくない「ほどほどの強さの運動」として、次のようなものが挙げられています。

- 早歩き
- ダブルスのテニス
- 軽い水泳
- 家事

**② 昔より「いま」**

参加者には、**この10年間にどれくらい運動してきたか**も聞いています。その分を差し引いても、**最近の運動の量が、その後の衰えと関係していました**。

{{< fukidashi who="reader" >}}
若いころは運動していなかったんですけど、今からでも遅くないですか？
{{< /fukidashi >}}

{{< fukidashi who="torapon" >}}
この研究では、**昔どうだったかより、いま続けているかのほうが大事**そうだ、という結果でした。研究チームも「**どれだけ長く動き続けるかが、カギかもしれない**」と話しています。
{{< /fukidashi >}}

## 気をつけて読みたいところ

希望のある結果ですが、次の点は心にとめておいてください。

- **くじ引きで「運動する組」「しない組」に分けた研究ではありません**。もともと病気の進みがゆっくりな人ほど、たくさん動ける、という面も考えられます
- 運動の時間は**本人の申告**です。実際より多め・少なめに答えた人もいるかもしれません
- 参加者は、はじめの時点で**頭の働きが比較的よい人**が多く、研究チームも「結果の受け止め方には注意が必要」としています
> 体を動かすと脳が変わっていく仕組みは、こちらでも紹介しています。

## いま、私たちにできること

- ☑ **「動いている時間」を、1週間の合計で考える**……散歩・買い物・掃除・庭仕事も、立派な活動です
- ☑ **激しさより、続けやすさ**……息が少しはずむくらいの早歩きなど、長く続けられるものを
- ☑ **休んでも、また再開すればいい**……研究では「いま」の運動が大事でした。何歳からでも、何度でも
- ☑ **安全第一で、主治医やリハビリの専門職に相談を**……パーキンソン病は転びやすくなることがあります。どんな運動が合うか、一緒に考えてもらいましょう

## おわりに

パーキンソン病と言われると、「これから悪くなる一方なのでは」と不安になるかもしれません。

でも今回の研究では、**体をよく動かしている人ほど、頭も体も、衰えがゆっくり**でした。しかも大事だったのは、激しい運動ではなく、**動いている時間を、いま続けていること**でした。

運動のおかげと言い切れる研究ではありません。それでも、毎日の暮らしの中で「動く時間」を少しずつ積み重ねることは、きっと無駄にはならないはずです。

※治療中の方は、運動の内容や量について、必ず主治医に相談してください。
